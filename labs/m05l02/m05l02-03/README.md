## Goal

You will be able to review code constructively and manage repository collaborators.

In the lesson: You can add a template to your repository so that every new pull request starts with the same structure. The template usually asks the author to explain what changed, and then provides a checklist. This simple file ensures that nobody forgets the basics, like adding tests and updating the documentation, before asking someone else for a review.

## Files

- [`starter/pull_request_template.md`](starter/pull_request_template.md): the listing from the lesson
- [`check.json`](check.json): how `./check` runs and checks this lab

## Steps

1. Read `starter/pull_request_template.md` alongside the lesson.
2. Follow it the way the lesson builds it:
   - Lines 1–2: what changed
   - Lines 3–7: a checklist
