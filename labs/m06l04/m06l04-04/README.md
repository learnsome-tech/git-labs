## Goal

Find which commit introduced a change using blame and bisect, and check out multiple branches at once with worktree.

In the lesson: Sometimes you need to urgently look at another branch, but your current working directory is full of uncommitted changes. Git work tree add creates a new folder next to your repository, linked to the same history, but with a different branch checked out. You can open that second folder in your editor, fix the bug, and delete the folder when you are done, without ever touching your main working directory.
