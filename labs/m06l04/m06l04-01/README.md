## Goal

Find which commit introduced a change using blame and bisect, and check out multiple branches at once with worktree.

In the lesson: When you need to know why a specific line of code exists, use git blame. It annotates each line of a file with the abbreviated hash, the author, the date, and the line number of the commit that last modified it. This helps you find the pull request where the change was reviewed, so you can understand the context behind the code.
