## Goal

Clean up a local branch by squashing, rewording, and reordering commits before sharing.

In the lesson: To start, run git rebase dash i, followed by how far back you want to go, like HEAD tilde three for the last three commits. Git opens your editor. After you save and close the todo list, git pauses if it needs a new commit message, for example when you squash or reword. Once you provide the messages, git rewrites the commits.
