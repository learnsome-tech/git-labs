# m04l03 · Fetch Is Not Pull

Module 4: Remotes · lesson 4.3 · Pro · [Open the lesson](https://learnsome.tech/learn/git-course/m04l03)

**Goal:** The learner can explain that fetch downloads commits without changing the working tree, while pull fetches and then merges.
