## Goal

Mark specific commits as releases using tags, push them to a remote, and associate them with GitHub Releases.

In the lesson: By default, when you push a branch to a remote, git does not send your tags. Tags must be pushed explicitly. You can push a single tag by providing its name instead of a branch name, or you can push every local tag at once by running git push with the tags flag.
