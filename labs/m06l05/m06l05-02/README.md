## Goal

Mark specific commits as releases using tags, push them to a remote, and associate them with GitHub Releases.

In the lesson: To create an annotated tag, run git tag with the a flag for the name, and the m flag for the message. If you run git tag on its own, it will list the tags in your repository. When you run git show on an annotated tag, git prints the tagger, the date, and the message, followed by the commit that the tag points to.
