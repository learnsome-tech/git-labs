## Goal

You will be able to prepare, name, and open a pull request.

In the lesson: Because a team might have dozens of branches in flight at once, clear names are essential. A good branch name tells your team what kind of work it is, what issue it solves, and what it does. A common convention is to start with a category like feature, bugfix, or chore, followed by a slash. If your project uses an issue tracker, put the issue number next, and finish with a short description. Use lowercase letters and hyphens to keep the names easy to read.
