## Goal

You will be able to install git, set the identity it writes into commits, and say which config file an answer came from.

In the lesson: Here are the honest routes, one per family of system. On a Debian or Ubuntu machine, install the git all package with apt; on Fedora, the same package with dnf. On a Mac there are two sensible answers: Homebrew, if you already use it, or the Apple command line developer tools, which carry git with them and which the system offers the first time you reach for it. On Windows, take the official installer from the git website, because it brings a bash shell along with the program; at a prompt, the same build arrives through winget. This panel is the one thing here not run for you: the machine that checks these lessons is a single operating system.
